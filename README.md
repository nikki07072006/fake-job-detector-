# Fake Job Offer Detector

A deep learning web application that detects whether a job message is FAKE or REAL using BERT and NLP.

## 🚀 Features
- Detects fake job messages instantly
- Works for email, WhatsApp, SMS
- Simple FAKE / REAL output
- User-friendly interface

## 🧠 Model
- BERT (Transformers)
- Binary classification
- Trained on fake job postings dataset

## 🛠 Tech Stack
- Python, Flask
- PyTorch, Transformers
- HTML, CSS

## ▶️ How to Run
pip install -r requirements.txt  
python app.py  

Open: http://127.0.0.1:5000
